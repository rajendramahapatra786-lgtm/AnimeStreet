# 📖 About

AnimeStreet is a modern Anime-themed E-Commerce website developed using Django.

The application allows users to browse products, manage their shopping cart, add products to their wishlist, place orders, upload payment proof, and manage their profile through a clean and responsive interface.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/AnimeStreet.git
```

Move into project

```bash
cd AnimeStreet
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py migrate
```

Start Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
